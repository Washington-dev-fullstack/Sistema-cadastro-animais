# Sistema-cadastro-animais
Sistema de cadastro de animais (cachorro ou gato) para adoção da ONG Patinhas Felizes, construído com classe abstrata, herança e polimorfismo
Nesse projeto, começa com 0 animais cadastrados esse número de cadastros vai aumentando conforme o usuário cadastra um animal. Permite, também, ver as informações de cada animal cadastrado.
